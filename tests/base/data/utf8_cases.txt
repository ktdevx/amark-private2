# The UTF-8 test vectors of amark_utf8_decode (13.1, 13.2). gen_utf8_cases.cmake
# turns every data line into one test of the suite utf8_cases_test_utf8_cases.
#
# A data line is
#   <name> | <input> | <expected>
# <name>      the test name: [a-z_][a-z0-9_]*, unique in this file.
# <input>     the input bytes, as two hexadecimal digits each, separated by spaces
#             (at least one byte).
# <expected>  what decoding the input from its start, one character after the
#             other, gives: U+<code point>/<consumed bytes> for each character,
#             separated by spaces. The consumed bytes add up to the input length.
# Lines that start with "#" and empty lines are ignored. A data line holds only
# printable ASCII other than ";", "[", "]", "\" and '"'.
#
# The expectations follow the Unicode Standard, chapter 3, section 3.9: the
# well-formed sequences of Table 3-7, and for an ill-formed sequence one U+FFFD
# for each maximal subpart (the longest initial part of a well-formed sequence,
# or else one byte). A byte that can never start a well-formed sequence (80-C1,
# F5-FF) is a maximal subpart of one byte by itself.
