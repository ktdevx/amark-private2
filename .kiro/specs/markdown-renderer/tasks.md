# Implementation Plan

> 前提：上流の実装が要る。`html-renderer`（`render.h`、`gen_html_cases.cmake`、`amark_test_html_gfm`）は 1.1 と 1.2 の前に、`block-parser`（`scan.h`、`commonmark.h`、`src/syntax/commonmark.c`、`gen_spec_examples.cmake`、`amark_test_parse`、`amark_test_parse_gfm`）は 3 の前に、`inline-parser`（`inline.h`、`amark_test_inline_gfm` と `amark_test_gfm_set_create`、`tests/spec/`）は 2.3 の前に要る。2 のテストは `syntax-tree` の `amark_test_tree` で組み立てた木だけを使い、パーサを使わない。3 のテストは、CommonMark の構文セットに組み込みの出力を足した構文セット（4.1 までは補助が足す）でパースと再パースをする。
> 公開ヘッダ `markdown.h` の宣言は 1.1 でまとめて置き、後のタスクはヘッダを変えずに実装を足す。`md_internal.h`、`src/CMakeLists.txt`、`tests/markdown/CMakeLists.txt` を多くのタスクが変えるので、2 と 3 のタスクは並列にしない。

  - `md_internal.h` に文脈の構造体と枠、区切り、並びの内部の型を置き、`src/render/md_*.c` と `src/syntax/md_*.c` をライブラリのソースの一覧に足す（中身はまだ空でよい）
  - オプションの初期化の関数が既定（印 0、保守的なエスケープ、style はすべて 0、報告先 NULL）を入れる
  - 公開ヘッダの検査（単独のコンパイルと正規の順）に通り、警告なしにビルドできる
